# QR CODE

### DESCRIPTION

    The function of this app is to generate qrcodes.

### Steps taken to develop the project

1. First step is to create a virtual environment.
2. The next is to create a .gitignore to make sure the virtual environment wont be added to the repository.
3. Then we activate the virtual environment.
4. Then we install the qrcode module with images.
5. Then create input for the users to inut urls and filename.
6. Then write a code to generate the qrcode.
7. Generate a code to pass the data into the qrcode and also the images.
